# ねずのばん ―午前三時―

深夜三時、寝落ちから目覚めると部屋の電気がつかない。
懐中電灯は、なぜか冷蔵庫の中にあった。——白い「顔」と一緒に。

**「顔」を二秒見つめたら、終わり。**

八月二十九日から三十一日までの三晩。電気のつかない部屋、行方不明の少女の張り紙、町に伝わる「おもてさま」の数え唄、そして深夜三時にピンポンを鳴らす "なお"。
俺を見張っているのは、病か、呪いか、それとも。

WebGL（three.js）で作った一人称 3D ホラーゲームです。3D モデルは Blender の Python スクリプトから（なおだけは、骨入りのテクスチャつきモデル `tools/blender/assets/nao/nao_rig.blend` にスクリプトでポーズをつけたもの）、効果音・環境音・囁き声はすべて WebAudio の数式から生成しています（外部の音源ファイルはありません）。全5章・エンディング3種、プレイ時間はおよそ40〜50分。

## 遊び方

```bash
npm install
npm run dev
```

ブラウザ（PC の Chrome / Edge / Safari / Firefox）で http://127.0.0.1:5173 を開き、「はじめから」。画面をクリックするとマウスで見回せます。**ヘッドホン推奨。**

| 操作 | キー |
|---|---|
| 移動 | W A S D / 矢印 |
| 見回す | マウス |
| 走る | Shift（足音が大きくなる） |
| 調べる・会話を進める | E / 左クリック |
| 懐中電灯 | F |
| 目を閉じる | Space 長押し |
| 持ち物 | Tab / I |
| ポーズ・設定 | Esc |

- 「顔」が画面の中心付近にあり続けると、心音と耳鳴りが強まり、二秒でゲームオーバー。視線をそらすか、目を閉じてやり過ごす。耳鳴りがしない白い顔は、たぶん人間。
- 目を閉じたままでも、直前に狙っていた物は調べられる。……ただし、目を閉じ続けると眠ってしまう。
- 迷ったら画面左上の目標を見ること。目標だけは嘘をつかない。
- 章の始めと要所で自動セーブされます（タイトルの「つづきから」）。暗すぎるときは Esc →「設定」の「明るさ」で調整できます。

## 開発

```bash
npm run typecheck   # 型チェック
npm run validate    # 章スクリプトが存在しないID（小道具・アンカー・文書・効果音…）を参照していないか検査
npm run build       # dist/ に本番ビルド（静的ファイル一式。どこのWebサーバーにも置ける）
npm run assets      # Blender で全3Dモデルを再生成（Blender 5.x。場所は BLENDER=... で指定可）
npm run upload      # ビルドして itch.io（nakajimakotaro/nezunoban の html5）へ butler で push。初回だけ butler login
```

開発サーバー（または URL に `?debug`）ではコンソールに `window.__kao` が生えます。
`__kao.chapters()` / `__kao.goto('ch3_night')` / `__kao.god()`（顔で死なない）/ `__kao.noclip()` / `__kao.auto(true)`（会話の自動送り＋ログ）など。

| 場所 | 内容 |
|---|---|
| `src/core/` | 描画（低解像度＋レトロなポストエフェクト）・入力・移動・当たり判定 |
| `src/world/` | 町の配置データ `layout.ts`、モデル仕様 `catalog.json`、照明・空・テクスチャ |
| `src/game/` | ゲーム進行・章スクリプトAPI（`Ctx.ts`）・「顔」・懐中電灯・セーブ |
| `src/game/chapters/` | 5つの章のスクリプト |
| `src/game/content/` | 文書・アイテム・店・エンディング・タイトル |
| `src/audio/` | 数式で合成する効果音ライブラリ |
| `tools/blender/` | 3Dモデル生成スクリプト（Blender Python） |

設計と章スクリプトの書き方は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)、物語の全容（ネタバレ注意）は [docs/SCENARIO.md](docs/SCENARIO.md)。

## 原案

深夜三時のチャットから生まれた企画です。「深夜3時の自宅」「電気がつかない」「冷蔵庫の中の懐中電灯と顔」「2秒見つめたらゲームオーバー」「昼の掲示板・神社・コンビニ」「睡眠障害」「深夜のピンポンと、なお」「なおの隠し事」——すべて作中に入っています。
