# 台本フォルダ（シナリオライター用）

ゲームに出る文章は、**このフォルダの `.nani` ファイルだけ**を書き換えれば変えられます。
プログラム（`src/`）を開く必要はありません。書き方は [Naninovel](https://naninovel.com/ja/guide/naninovel-scripts) のスクリプトに寄せてあります（ただのテキストファイルなので、メモ帳でも VS Code でも開けます）。

| ファイル | 中身 |
|---|---|
| `ch1.nani` 〜 `ch5.nani` | 各章の台詞・モノローグ・ナレーション・選択肢・目標・ヒント・調べたときの反応 |
| `docs.nani` | ゲーム内で読む文書（メモ・張り紙・日記・スマホのトーク画面など） |
| `endings.nani` | エンディングの名前とエンディングロール |
| `items.nani` | アイテムの名前と説明、お店の品物の名前と説明 |
| `common.nani` | どの章でも共通の「調べたときの反応」（章で特に決めていない物の表示と心の声） |
| `system.nani` | 話者の一覧、タイトル画面・ヒント集・クレジット・ゲームオーバー画面、通知などのシステム表示、人の呼び名 |

`docs/SCENARIO.md` は設計時の原稿です。**実際にゲームに出る文はこのフォルダが正**です。

壁の張り紙・カレンダーなど**3D空間に絵として描いてある文字**は、ここではなく `src/world/textures_content.ts` にあります（位置合わせと一体のため）。張り紙を調べたときに読める文は `docs.nani` なので、張り紙の文を変えるときは両方をそろえてください。

## 書き方

```
; ==== ドアの前 ====        ← ; で始まる行はコメント（ゲームには出ない）

# washer_face              ← ここから1かたまり（ブロック）。# のあとがブロックの名前
; 洗濯機の顔を見たとき
……見るな。なぜか、そう思った

# nao_door
; ドアを開けたとき
なお: 起きてる？
なお: ……ごめん。なんでもない
透: なお？
ナレ: その夜は、それきりだった。
```

- **`# 名前`** から次の `#` までが1つのブロックです。
  - `#` のあとの名前で、プログラムが文章を呼び出します。**名前は変えないでください**。
  - ブロックを消したり、名前を打ち間違えたりすると、ゲーム中に【ch1.washer_face】のような表示が出ます。
- **1行 = 1ページ**（クリックで次へ進む単位）です。行を増やせばページが増え、減らせば減ります。
- 台詞の書き方
  - `なお: ……` … 話者つきの台詞。コロンは半角 `:` でも全角 `：` でも構いません。話者名は `system.nani` の `speakers` に載っている名前だけ使えます（新しい人物はそこに足す）。
  - `ナレ: ……` … 画面中央のナレーション。
  - それ以外の行 … 主人公（透）の心の声（モノローグ）。
  - 心の声なのに `名前: …` の形になってしまう行は、行頭に `\` をつけます（例: `\なお: 起きてる？、とだけ来ていた`）。
  - 話者が続くと、同じウィンドウでページ送りになります。話者が変わるとウィンドウが切り替わります。
- **`{n}` のような波かっこ**には、ゲームが数字や名前を差し込みます（例: `あいているところを全部しめる（{n}/5）`）。波かっこの中は変えないでください。
- 行頭に `#` や `;` を本文として書きたいときは `\#` `\;` と書きます。

### ブロックの種類（ブロックの名前のつけ方で見分けがつきます）

| 名前の例 | 何に使われるか | 書き方 |
|---|---|---|
| `title` `subtitle` | 章の扉（「一日目」「八月二十九日　午前三時」） | 1行 |
| `gameover` | その章で顔に殺されたときのゲームオーバー画面の文 | 1行 |
| `obj_〜` | 画面左上の「目標」 | 1行 |
| `hint_〜` | 画面左下の操作ヒント | 1行 |
| `label_〜` | 物に照準を合わせたとき出る「〜を調べる」 | 1行 |
| `toast_〜` | 画面右の小さな通知 | 1行 |
| `sub_〜` | 目を閉じている間などに出る字幕（ウィンドウを出さない） | 1行（`なお: …` 可） |
| `choice_〜` | 選択肢 | **1行 = 選択肢1つ**。行の数・順番は変えないでください（順番で分岐しています） |
| それ以外 | 会話・モノローグ・ナレーション | 上の「台詞の書き方」 |

文書（`docs.nani`）は、ブロックの中身がそのまま紙に書いてある文になります（空行もそのまま）。
スマホのトーク画面の文書は `なお: 本文` が吹き出し、`--- 4月26日` が日付の区切りです（こちらは台詞ではなく画面の表示です）。

## 書き換えたら確かめる

```bash
npm run dev
```

で開いたゲームは、`.nani` を保存すると自動で読み直されます。

```bash
npm run validate
```

は、プログラムが呼んでいるブロックが台本にちゃんとあるか、話者名が一覧にあるかを調べます。
