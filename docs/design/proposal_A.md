# 案A（心理ホラー寄り）シナリオ企画書 ——『ねずのばん』

> 切り口: 睡眠障害（夢遊・入眠時幻覚・記憶の欠落）。「顔」は主人公の妄想だと強く匂わせながら、最後に一つだけ「それでは説明がつかない」ものを残す。主人公のモノローグは信用できない。

---

## 1. タイトル案

1. **『ねずのばん』**（推し）— 「寝ずの番」。眠れない主人公、眠る主人公を見張る「顔」、そして毎晩彼を見つめていた"誰か"。三つの意味を重ねる。
2. **『おもてに出るな』** — 町の言い伝え「夜におもて（外）に出たらいかん、おもて（面）さまが見とる」の掛け言葉。
3. **『午前三時、目をとじて』** — 生存ルール「目を閉じる」と、消えた少女の最後の言葉をそのまま題にする。

## 2. ログライン

深夜三時、寝落ちから目覚めると部屋の明かりがつかない。いつもの引き出しにない懐中電灯は、なぜか冷蔵庫の中にあった。その奥に、白い「顔」がいた。夜ごと抜け落ちる記憶。身に覚えのないレシートと発信履歴。一年前この部屋から消えた少女。そして深夜にピンポンを鳴らす"なお"。俺を見張っているのは呪いか、病か、それとも——。

## 3. 案Aの方針（怖さの設計）

- **怖さの主語を「顔」から「自分」へずらす。** 中盤からプレイヤーは「顔より、眠っている間の自分のほうが怖い」と感じるようにする。
- **主人公・透のモノローグは嘘をつく。** 本人は嘘だと思っていない。「最近は夜ちゃんと寝てる」「なおがこの部屋に来たのは一回だけだ」と言い張るが、画面に出る証拠（レシート、発信履歴、張り紙、店員の証言）がそれをくつがえす。
- **すべての怪異に合理的な説明を用意し、九割まで説明しきる。** 残りの一割（留守番電話の一致）だけは最後まで説明させない。
- **ゲームの生存ルールを物語に重ねる。** 「目を閉じればやり過ごせる」というルールは、消えた少女・しずくの最後の言葉そのものだった。

## 4. 真相の全容

### 事実として確定していること
- 主人公・瀬尾透（25）は、この春コーポ月見103号室に越してきた。家賃は相場よりかなり安い。もともと不眠気味だったが、入居後に夢遊（睡眠時遊行症）と入眠時幻覚が悪化し、6月から睡眠外来に通っている。本人は「ただの不眠」だと思い込んでいる。
- 103号室の前の住人は大学生の宮内しずく（当時19）。彼女も夜中に裸足で歩き回り、日記に「顔が見てる」と書いていた。**去年の8月31日午前3時ごろ**、近所で目撃されたのを最後に行方不明になり、今も見つかっていない。
- なお（宮内なお・24）はしずくの姉。妹の部屋に男が越してきたと知り、偶然を装ってコンビニで透に近づいた。遺品整理のときに作った**合鍵**を持っている（大家は鍵を替えていない）。透が眠っている深夜に、何度も部屋に入っていた。
- 部屋でなおが見たのは、眠ったまま起き上がって歩く透だった。透は寝言で、妹しか知らないはずのことを妹の口調で話した。なおはそれを撮影・録音し、毎晩それを聞きに通うようになった。透に病院を勧めなかったのは「治ったら、もう妹の声が聞けなくなる」から。
- 一年前の8月31日午前3時2分、しずくはなおに電話をかけた。なおは寝ぼけて出なかった。**留守番電話が一件残っている。なおは怖くて、一年間一度も再生できていない。**
- 本編は8月29日〜31日の三晩。三晩目は、しずくが消えてちょうど一年の夜にあたる。

### 読み①：心理（病）
- 明かりを消し、ブレーカーをテープで留め、懐中電灯を冷蔵庫に入れたのは、夢遊中の透自身。「電池は冷やすと長持ちする」は、入居時に大家から聞いた話を寝ぼけて再現したもの。
- 暗闇に浮かぶ白い「顔」の原型は、スマホの画面に下から照らされて透を見下ろしていたなおの顔。半分覚醒した脳がそれを、冷蔵庫やトイレ（夢遊中に透が立ち尽くす場所）に貼りつけた。
- 寝言の"しずく"は、眠る透の枕元でなおが毎晩ささやいた思い出話を、脳が再生したもの。日記は透の筆跡で、夢遊中に透が書いた。
- 「見張られている」感覚は妄想ではなかった。**本当に毎晩見張られていた。なおに。**

### 読み②：呪い（おもてさま）
- 月見町には「おもてさま（面様）」の言い伝えがある。からだを失くした者たちが白い顔だけになり、眠りの浅い者のからだにある"すきま"を覗く。目が合えば、すきまから中へ入られるか、向こうへ連れていかれる。
- 一年前、しずくはおもてさまに連れていかれかけて、からだを失くした。けれど目をつぶっていたので、向こうへは行ききらなかった。しずくは同じ部屋で眠る透のからだの"すきま"に入り込み、夜ごと透のからだで姉を呼んでいた。
- 顔たちが見張っていたのは透ではない。**透の中にいる、しずくだ。** 2秒目が合えば、からだごと持っていかれる。

### どちらでも説明がつかない、ただ一つのこと
- 最終盤、目を閉じたまま眠りに落ちた透は、しずくの口調で話し出す。その言葉は、なおが一年間一度も再生しなかった留守番電話と一字一句同じだった。なおは中身を誰にも話していないし、眠る透にも聞かせていない。そもそも彼女自身が聞いていないのだから、話せるはずがない。

## 6. なおの隠し事と、その明かし方

### 隠し事（終盤で四段階に明かす）
1. しずくの姉であること。透に近づいたのは、妹の部屋に入るためだった。
2. 合鍵で、透が眠っている深夜に何度も部屋に入っていた。一日目の夜もいた。透が急に起きたので、クローゼットに隠れて目を閉じていた。
3. 眠ったまま話す透を撮影・録音し、そこに妹の声を聞いていた。病院を勧めなかったのは「治ったら、もう聞けなくなるから」。
4. 一年前の午前3時、しずくからの電話に出なかった。その留守番電話を一度も聞けていない。

### 明かし方の要点
- 告白の場面は三日目深夜、透が**開いた冷蔵庫の前で**目覚めた直後。振り返ると、暗い部屋のベッドの上に白い顔が浮いている。近づくと、スマホの明かりに照らされたなおだと分かる。「顔」とまったく同じ見え方を先にプレイヤーに体験させてから、告白に入る。
- 告白は選択肢（聞く／拒む）で段階的に進む。どちらを選んでも最後まで聞けるが、信頼度フラグ `nao_trust` が変わり、エンディング分岐に効く。
- なおのスマホ動画（文書D14）で、夢遊中の透が懐中電灯を冷蔵庫に入れる場面を見せる。一日目の疑問「誰がここに懐中電灯置いたんだ」に、ここで"答え"が出る。ただし動画の最後で、眠っている透はカメラのほうを向いて言う。「お姉ちゃん、撮らないで」。

## 9. 章ごとの展開

### 第1章「一日目　午前三時」（ch1_night1）
**目標**: 明かりをつける → 懐中電灯を探す → ブレーカーを確かめる → 部屋の"すきま"をすべて閉じる（0/4）→ ベッドで眠る

**状況**: 冒頭のモノローグは（机で寝落ちしたはずだった。目が覚めたのは、ベッドの上だった）。最初の一行で記憶の欠落を示す。VHS表示は「AM 3:00」。スイッチは洋室もキッチンもつかない。スマホは充電されておらず電源が入らない。それなのに電子レンジの時計は「3:00」と光り、冷蔵庫は唸っている。停電ではない。部屋で唯一の光は、少しだけ開いた冷蔵庫の扉から漏れる庫内灯。

**主な流れ**
1. いつも懐中電灯を入れている引き出しには、単三電池が2本あるだけ。`[ITEM+:battery]`（本体だけ、ない）
2. **顔1**　`[FACE:anc_washer_inside:fleeting]` 冷蔵庫へ向かう途中、洗濯機の丸窓に白い顔が浮かぶ。心音・耳鳴り・ノイズが急速に高まり、モノローグ（……見るな。なぜか、そう思った）。目をそらすと消える。これでルール①「見つめ続けてはいけない」を体で覚える。
3. **顔2**　`[FACE:anc_fridge_inside:static]` 冷蔵庫を開けると、麦茶と卵のあいだに懐中電灯。その奥、棚の向こうに顔がいる。モノローグ（見なければいい。……目を閉じて、手を伸ばせ）に合わせて「Space長押し：目を閉じる」のヒントを出す。目を閉じたまま「懐中電灯を取る」。指先に冷たいもの、耳元に誰かの息 `[SE:breathing]`。扉を閉め、目を開けて、
   透「誰がここに懐中電灯置いたんだ…？ 誰かに中にはいられてる…？」
   これがルール②「目を閉じれば、見たことにならない」。**チェックポイント。**
4. 懐中電灯で玄関上の分電盤を照らす。「照明」「洋室」の分岐ブレーカーが落とされ、マスキングテープで留めてある。メモ（D2）が貼ってある。テープを剥がして上げると部屋に光が戻るが、3秒後、誰も触っていないのに `[SE:breaker]` で落ちる。二度目も落ちる。三度目は、何かに押さえられているように上がらない。
5. 冷蔵庫の扉にマグネットで留めたメモ（D3）を見つける。「ねるまえに　あいてるところを　ぜんぶ　しめる」。透（俺の字じゃない。……でも、うちのメモ帳だ）
6. "すきま"を閉じる（順不同）
   - トイレのふた　**顔3**　`[FACE:anc_toilet_bowl:static]` 目を閉じてふたを閉め、流す。`[SE:toilet_flush]`
   - クローゼットの隙間　**顔4**　`[FACE:anc_closet_gap:peek]` 半分だけ覗く顔。目をそらしてから、目を閉じて戸を閉める。（真相：この夜クローゼットに隠れていたのはなお。ただし彼女も目を閉じていたので、覗いていた顔が誰だったのかは最後まで分からない）
   - カーテンの隙間　**顔5**　`[FACE:anc_window_outside:fleeting]` ベランダのガラスの向こう。
   - 冷蔵庫の扉：さっき閉めたはずなのに、また少し開いて光が漏れている。顔はいないが `[SE:breathing]`。
7. 四つ閉じると目標が「ベッドで眠る」に変わる。メモの最後の一文は「さいごに　め」。ベッドで目を閉じると、耳元で `[SE:whisper]`「……おやすみ」。`[FADE_OUT]` → 第2章。

**補足**: 玄関から外廊下にも出られる。蛍光灯が明滅し、遠くで `[SE:footsteps_outside]` が聞こえる。目標はすべて部屋の中にあるので、プレイヤーは自然に戻ってくる。
**顔の出現**: 5回。1〜2は必ず遭遇する（チュートリアル）。3〜5は順不同。

### 第2章「一日目　昼」（ch2_day1）

## 13. 特に怖い場面ベスト5

1. **冷蔵庫の懐中電灯**: 真っ暗なキッチンで、光っているのは庫内灯だけ。目を閉じて手探りで懐中電灯を取る。指先に触れる冷たさと、耳元にかかる息。
2. **ピンポンとドアスコープ**: 覗き穴の白い顔から目をそらすと、ノックと「透くん？」の声。もう一度覗くと、スマホに照らされたなおの顔がある。同じ高さで、同じ白さ。安堵がのちにもう一度恐怖に変わる。

5. **なおの動画**: 眠っている透がカメラのほうを向き、透の声で「お姉ちゃん、撮らないで」。

## 15. 実装メモ

- **台詞量の見積もり**: 約360行（第1章50／第2章70／第3章90／第4章70／第5章60／エンディング各10〜20）。文書16、アイテム9、NPC5。
- **主なフラグ**: `nao_trust`（-1〜2）、`diary_read`、`ema_seen`、`hairpin`、`rec_on`、`phone_answered`、`omamori_used`。
- **理不尽な死をなくすために**: 顔はどれも、出る前に予兆（`[SE:whisper]`、心音、照明の明滅、モノローグ）を挟む。最初の2回でルール（目をそらす／目を閉じる）を教え、3回目以降もゲージの溜まり始めには必ず音で知らせる。
- **"顔に見えるなお"の扱い**: 第3章のドアスコープと第5章のベッドの上で、なおはスマホの光に照らされて白く浮かぶ。これは `FACE` ではなく NPC の演出（顔だけを照らすライト）にして、凝視ゲージは溜めない。ただし心音だけは鳴らし、プレイヤーには区別できないようにする。
- **追加してほしい効果音**: `tape_peel`（テープを剥がす）、`tv_on`（ブラウン管がつく音）、`voicemail`（留守電の再生ガイド音）。
- **昼に顔を出さない原則**: 守る。END3の「目を閉じた写真」は顔の出現ではなく、文書の差分として表現する。
