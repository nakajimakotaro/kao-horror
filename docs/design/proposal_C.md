# 案C（ヒトコワ寄り）シナリオ提案書

> 切り口: 「誰かに中に入られている」という疑念 × なおの隠し事。人間の怖さ（執着・嘘・監視・秘密）で真相を組み、「顔」は超常とも妄想とも最後まで決めきらない。
> 規模: 全5章＋エンディング3種／約35〜45分／台詞・モノローグ約330行／文書15／アイテム11／NPC5

## 1. タイトル案

1. **『ねむっていられますように』**（推し）— 神社の絵馬に書かれた、なおの願い。可愛い祈りに見えたものが、終盤「眠らせ続ける」という意味に反転する。
2. **『見張り様』** — 町の伝承の名。見張っているのは誰で、見張られているのは誰か。
3. **『103号室、午前三時』** — 場所と時刻だけの即物的な題。実話怪談・ヒトコワ動画の手触りに寄せる。

## 2. ログライン

寝落ちから目覚めた深夜三時。電気のつかない部屋で、懐中電灯は冷蔵庫の中にあった——白い「顔」と一緒に。夜ごとに浮かぶ顔は、なぜかいつも“誰かがいた場所”に現れる。作った覚えのない麦茶、覚えのない送信履歴、二年前に同じ部屋から消えた男。そして深夜三時にチャイムを鳴らす、優しいなお。呪いか、妄想か、それとも——人間か。

## 3. 案Cの芯

**「顔が出た場所には、誰かが“いた”。」**
夜は顔から目をそらしてやり過ごし、どこに出たかを覚えておく。昼、その場所を明るいうちに調べ直すと、人間の痕跡（足跡・薬・カメラ・日記）が出てくる。顔は恐怖の対象であると同時に、唯一の“指差し”でもある——そう気づいた瞬間、怖さの矛先が「顔」から「人間」へ反転する。

## 4. 真相の全容

### 4-1. 時系列（作中では断片でしか明かさない）

- **二年前**: 調剤薬局の薬剤師・篠宮なおが、コーポ月見103号室の住人・久世拓海と親しくなる。なおは合鍵を作り、久世の麦茶に睡眠薬を混ぜ、夜ごと部屋に入って寝顔を見つめた。久世は「夜中に白い顔が見える」と日記に書き、神社で「見張り様」の話を聞く。
- **二年前の8月13日（お盆の入り）**: 久世はなおに「鍵を返してくれ」と告げる。その夜もなおは麦茶に薬を入れ、そのまま部屋で眠ってしまう。明け方、久世は消えていた。部屋には「顔だけがいっぱいあった」となおは言う。以後、久世は行方不明。
- **その後**: なおは空き部屋になった103号室に、合鍵で夜な夜な入り続けた（向かいのトメさんが目撃）。
- **一年前**: 桐生朔が入居。久世が隠した日記は、クローゼットの天袋の奥に残ったまま。
- **四か月前**: 朔、軽い不眠で睡眠外来へ。処方箋を持ち込んだ「みどり調剤薬局」で薬を渡したのが、なお。数日後、コンビニで「偶然」声をかけてくる。
- **三か月前〜**: 付き合っているのかいないのか曖昧な関係。なおは靴箱の予備の鍵を持ち出し、久世のときと同じことを始める——麦茶に薬、煙感知器に小型カメラ、朔のスマホからバイト先や母親へ返信して、少しずつ外の世界から切り離す。朔の「睡眠障害」を悪化させたのは彼女。
- **本編初日の深夜**: 朔は麦茶を飲む前に寝落ちしたため薬が効かず、チェーンもかけ忘れていた。午前三時、麦茶を作り替えに来ていたなおの気配で目を覚ます。

### 4-2. 「なぜ朔は『顔』に見張られるのか」——三つの読み

1. **人間の読み（主軸・確定する）**: 朔は本当に見張られていた。カメラで、そして毎晩ベッドの脇に立つなお本人に。顔が出るのは、なおが潜んだ場所・隠し物をした場所ばかり。
2. **呪いの読み**: 見張り様は家の守り神。よそ者が家に入り込むと、家の主に白い顔を見せて知らせる。顔は朔を見ていたのではなく、**朔の“後ろ”にいる者**を見張っていた。目を合わせ続けると、見張り様が見ているもの（＝入り込んだ者）とこちらの目が合ってしまう——これがゲームオーバー[GAMEOVER:目が合った]の意味で、その瞬間の囁き「……おきちゃった？」が、三章以降なおの声だと分かる。舞台がお盆の入りであることも「帰ってくるもの」の気配として効かせる。
3. **妄想の読み**: 顔は、薬で歪んだ脳が見せた入眠時幻覚にすぎない——はずなのに、子どもも、なおも、カメラも、同じ場所に白いものを見ている。そして最終章のなおは、この読みを**朔を縛る道具**に使う（「また夢見てたんだよ。朔くん、病気なんだから」）。

## 5. なおの隠し事と、その明かし方

### 5-1. 隠し事（最終章、チェーン越しにすべて明かされる）

1. **合鍵** — 靴箱の予備の鍵から合鍵を作り、毎晩入っていた
2. **麦茶** — 朔の処方薬と、勤め先から持ち出した睡眠薬を混ぜていた
3. **カメラ** — ベッド真上の煙感知器に仕込み、スマホで寝顔を見ていた
4. **スマホ** — 朔になりすまし、バイト先に「辞めます」、母親に「しばらく連絡できない」と送っていた
5. **久世** — 二年前、同じ部屋で同じことをしていた。久世は消えた

なおの言い分は一貫して「守ってた」。「三時に起きると顔が見えるの。見た人は連れていかれるの。たくみくんみたいに。だから朝まで眠らせてあげてたの」。本気で見張り様を恐れているのか、執着の言い訳に伝承を使っているのかは断定しない。
