# 案B『夜見の番』— 民俗ホラー寄りシナリオ案

> 原案の確定要素1〜14をすべて満たしたうえで、「顔」を、この町にかつてあった夏の夜番〈寝ずの番〉の成れの果てとして組み直した案。
> 規模: 5章＋エンディング3種／35〜45分／台詞・モノローグ約400行／文書16／アイテム11／NPC5

## 0. この案の尖らせ方
- **操作ルール＝言い伝えの作法**。「目をそらす」「目を閉じる」「閉じたまま取る」「穴をふさいで眠る」「懐中電灯」が、すべて民俗の"作法"として意味を持つ。
- **なぜ午前3時か／なぜ2秒か／なぜ顔だけか／なぜ主人公か**を、ひとつの言い伝えから論理的に導く。同時に、すべての怪異に「睡眠障害（夢遊・睡眠麻痺・出眠時幻覚）」と「人間（なお）の仕業」という現実の説明も用意し、**最後まで呪いとも妄想とも決めない**。
- 時期は八月十一日〜十三日。最終夜はお盆の入り（迎え火）で、なおの兄が消えてちょうど三年目の夜。

## 1. タイトル案
1. **『夜見の番（よみのばん）』**（本命）夜を見張る番＝黄泉（よみ）の番。副題「午前三時、目を合わせるな」
2. **『ふたつ数えたら』** 2秒ルールと数え唄から
3. **『午前三時の顔合わせ』** 「顔合わせ」＝初対面の挨拶と、番の引き継ぎの二重の意味

## 2. ログライン
寝落ちして目覚めた午前三時。電気のつかない部屋で、懐中電灯はなぜか冷蔵庫の中にあった——白い「顔」と一緒に。眠れない青年・透は、かつて"寝ずの番"の村だったこの町で、自分がすでに「次の番人」に選ばれ、引き継ぎの作法をひとつずつ済まされていることを知る。最後の作法は、顔と目を合わせて、ふたつ数えること。

## 3. 真相の全容

### 3-1. 言い伝え（呪いの論理）
- 月見町の旧名は**夜見村（よみむら）**。「黄泉に通じる」と昭和に改名されたが、神社だけは今も**夜見神社**を名乗る。
- 江戸の頃、村では盆の八月、村境の祠の前で一晩中起きている**寝ずの番**を立てた。番人は提灯（**番の灯**）と**鈴**を持ち、**八つ半（午前三時ごろ）**に鈴を鳴らして夜明けまで村を見張る。
- 寛政のある夏、番人の**与一**が八つ半に居眠りし、その間に子ども三人が消えた。村人は「二度と眠れぬように」と与一の**瞼を断ち**、祠に籠めた。与一は死に、名は帳面から墨で消された。
- 以来、八月の八つ半になると、**瞼のない与一の顔**が「起きている者」を探しに来る。番を渡せば、自分はやっと眠れるからだ。
- 引き継ぎには**四つの作法**がある。①**灯を渡す** ②**鈴を持たせる** ③**番帳に名を記す** ④**目を合わせて「ひとつ、ふたつ」と数える**（昔の夜番は交代のとき、互いの目を見て二つ数えてから提灯を渡した）。
- 番を受け取った者は体を失い、**顔だけ**になる（番人に要るのは目だけ）。これが「八月の深夜、自宅を出たまま行方不明」の正体。
- だが**番を渡しても前の番人は帰ってこない**。与一が眠らない限り顔は増え続け、全員が"見張り"として次の番人を見張る。
- 番そのものを眠らせる法はひとつ。**灯と鈴を祠に返し、消された初めの番人の名を呼ぶ**。名は帳面からは消されたが、子どもの**数え唄**にだけ残っている。
- 顔は**鏡・水面・戸の隙間などの"穴"**からのぞく（葬式で鏡に布をかけるのと同じ理屈）。**天井灯のついた部屋には出ない**。**眠っている者＝目を閉じた者には番を渡せない**。

### 3-3. 核心（主人公が「顔」に見張られる理由）
透を見張っているのは、前の住人でなおの兄・航を含む**歴代の番人たち**だ。彼らは**次の番人である透が眠らないように**、毎晩三時に起こしに来る——かつて村人が与一を見張り、瞼を切ってまで眠らせなかったように。透はすでに作法①〜③を済まされ、残るのは④だけ。そして透をこの部屋へ連れてきたのは、なおだった。

## 4. なおの隠し事とその明かし方

### 4-1. 中身（第5章で本人が明かす）
1. フルネームは**宮下なお**。三年前の八月十三日に**この103号室から消えた宮下航の妹**。
2. 宮下家は代々の**番元（ばんもと）**——次の番人を選び、番帳に名を記す家。家の口伝では「番を渡せば前の番人は帰ってくる」（宮司は否定する）。
3. 東京の睡眠外来の待合で「三時に目が覚めると白い顔が見える」と話す透を見つけ、近づいた。家賃の安い103号室を勧めたのも、なお。
4. **兄の合鍵**で夜ごと部屋に入り、ブレーカーを落としてテープで留め、トイレのふたを開け、鏡の布を外していた。蔵の番帳に透の名を書いたのも、なお。
5. だが透を本気で好きになり、ずっと揺れていた。三時のインターホンは、透が**まだ起きている＝まだ透のままか**を確かめるため。テープの「あげるな」は、ブレーカーを上げに戻りたくなる自分への言葉。
6. ただし**冷蔵庫の懐中電灯・浴槽の水・電球**については「知らない」と言う。ここだけは最後まで誰の仕業か確定させない（呪い／夢遊の両読み）。

### 第1章「一日目　午前三時」寝落ち（8/11深夜・約8分）
**目標**: 部屋の電気をつける → 懐中電灯を探す（いつもはキッチンの引き出し）→ ブレーカーを確かめる（玄関の上）→ 水の音を確かめる → 電気を戻す → 戸締まりを確かめる → 眠る
- 机に突っ伏して寝落ちしていた。暗転のまま[SE:phone_vibrate]。VHS表示3:03。通知「なお：起きとる？」の直後、スマホは電池切れ。
- スイッチは無反応。カーテンの外の街灯はついている（停電ではない。この部屋だけ）。
- 引き出しは空。冷蔵庫の扉の隙間から白い光が漏れている——電気は来ていないのに、モーター音もしないのに。扉にはなおのメモ。

- ブレーカーは落ち、養生テープで留めてある。手書きで「八つ半すぎるまで　あげるな」。上げると一瞬ついて、また落ちる。[SE:water_drip]

- 夜の外出は任意（自販機の灯り、明滅する街灯。掲示板は暗くて読めない＝昼への引き）。

## 9. エンディング（3種）

2. なおが目を開けようとする。[CHOICE]（制限5秒） 1)「なおの目をふさぐ」 2)「俺が代わる」 3)「……動けない」／時間切れ

**END1『おやすみ』** 透「——与一」。鈴が一度だけ、ひとりでに鳴る。長い長い吐息。瞼の裏の白さが、ひとつずつ消えていく。夜明けのカラス。駆けつけた宮司「……眠れたんやな、与一さん」。昼、なおは兄の張り紙を自分ではがす。なお「もう、待つのやめる」。透は睡眠外来に予約を入れる。主人公（医者は"睡眠麻痺と幻覚"と言うだろう。宮司は"与一さんがやっと眠れた"と言った。どっちでもいい、と思えた）。ラスト、午前2:52、なお「起きとる？」——既読はつかない。透は眠っている。

**END2『八つ半の顔』** 目を開ける。目の前に、濃いくまの目。ひとつ。ふたつ。白。——昼の掲示板。航の張り紙の隣に新しい一枚「早瀬透（26）8月13日深夜、自宅を出たまま」。なお「……帰ってこんやん。お兄ちゃんも、透も」。ラスト：深夜三時の103号室。新しい住人が寝返りを打つ。冷蔵庫の隙間から、白い光。
